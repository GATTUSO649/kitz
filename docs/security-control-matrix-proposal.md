# KitCulture 47-Control Security Matrix Proposal

**Status:** Proposed baseline; owner approval required. The repository did not contain the referenced original 47-control specification. This document is not a certification or a claim that the controls have passed. It is a traceable replacement proposal for review.

**Assessment basis:** Read-only source/documentation inspection and the 2026-11-02 security assessment. No penetration test, production login, live payment, migration, or destructive test was performed during this inspection. Baseline automated checks: `npm test` (113 passed), `npm run typecheck` (passed), `npm run build` (passed), `npm run lint` (existing React hook warnings). Each control still requires control-specific evidence before it can be marked verified.

Status vocabulary: `Observed` means related implementation exists, not that the whole control passed; `Partial` means gaps are already documented; `Not verified` means evidence is insufficient; `Approval required` means owner decision or controlled environment is a prerequisite.

## Approval and completion gates

1. Owner reviews and approves or replaces this proposed baseline; do not describe it as the original specification.
2. Assign a named owner and evidence source per control.
3. Run security verification only in authorized local/staging environments; production changes require separate approval.
4. Mark a control verified only after the recorded test/evidence passes. Findings and exceptions remain visible.
5. Reassess the matrix after RBAC, independent frontends, finance/refunds, inventory, marketing, and Operations identity work.
